# Program Survey Dashboard and Stakeholder Reporting

This project validates program-participation records and generates the five résumé-stated views: participants by department, partnerships by type, average satisfaction by impact area, total funding by impact area and student volunteers. It creates a one-page PNG dashboard and an Excel-ready summary workbook from a documented synthetic sample so no confidential participant data is published.

Run `pip install -r requirements.txt`, `python src/build_dashboard.py --input data/sample_program_data.csv`, then `pytest`.
